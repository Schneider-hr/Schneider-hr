## How I write things up

- **Active testing only touches systems I own or lab machines built for the exercise.** OSINT work uses public sources only.
- **Failures stay in.** Uncracked hashes, blocked exploits, and misdiagnosed faults are documented next to the successes, because that is what real testing looks like.
- **I say what was and wasn't done.** Group work is marked as group work, and simulated or partial results are labelled that way.
